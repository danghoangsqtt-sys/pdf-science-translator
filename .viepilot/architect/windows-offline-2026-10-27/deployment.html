Đóng gói Windows

Build có thể chuẩn bị tài nguyên trước; sử dụng trên máy người dùng phải hoàn toàn không cần Internet.

Windows trước
Nguồn sơ đồ Mermaid · lưu cục bộ
flowchart TD
  BUILD[Build environment: prepare approved assets] --> PACK[Windows app + full offline data pack]
  PACK --> USB[Local distribution / USB]
  USB --> VERIFY[Verify manifest / hash / compatibility]
  VERIFY --> UI[Desktop UI]
  UI --> API[Loopback API: per-session token]
  API --> WORKER[Managed child worker]
  WORKER --> ASSETS[Local verified resources]
  WORKER --> CACHE[Local cache / staging]
  UPDATE[Local update package] --> VERIFY
  DENY[Runtime Internet: no path]
