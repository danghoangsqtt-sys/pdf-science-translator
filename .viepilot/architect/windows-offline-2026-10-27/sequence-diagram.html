sequenceDiagram
  actor User
  participant UI
  participant API as Local API
  participant Worker as Local Worker
  participant PDF as PDF Pipeline
  User->>UI: Chọn PDF + profile
  UI->>API: POST job (profile only)
  API->>API: Validate token, offline policy, assets
  alt thiếu dữ liệu
    API-->>UI: LOCAL_DATA_MISSING
  else sẵn sàng
    API->>Worker: private resolved configuration
    Worker->>PDF: safe processing in staging
    PDF-->>API: progress + kept-source reasons
    API-->>UI: public progress / sanitized warnings
    User->>UI: Hủy (tùy chọn)
    UI->>API: POST cancel
    API->>Worker: cancel event
    Worker-->>API: stop at safe boundary / complete
    API-->>UI: cancelled / complete / partial / error
  end

Hủy và sự cố

Q01

Không hứa dừng một lệnh suy luận ngay tức thì nếu runtime không hỗ trợ preemption. UI có trạng thái “Đang dừng an toàn”; backend đặt timeout hữu hạn và không bàn giao staging chưa kiểm chứng.

Worker chết → đánh dấu lỗi trung tính, dọn vùng tạm, giữ nguồn; chỉ khởi động lại có giới hạn. Không tự chuyển ra mạng hoặc tự giảm mức người dùng đã chọn.
