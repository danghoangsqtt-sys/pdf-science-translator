Luồng dữ liệu

Ngoại tuyến không đồng nghĩa dữ liệu đã được mã hóa hay xóa tự động; từng nơi lưu phải có chính sách rõ.

Windows trước
Nguồn sơ đồ Mermaid · lưu cục bộ
flowchart LR
  SOURCE[Source PDF: immutable] --> CHECK[Preflight]
  CHECK -->|ready| STAGE[Local staging]
  CHECK -->|not ready| ERROR[Sanitized public error]
  STAGE --> PROCESS[Layout / optional safe OCR / translation]
  PROCESS --> GUARD[Formula / style / term / fit guards]
  GUARD -->|safe| OUTPUT[Separate output PDF]
  GUARD -->|unsafe segment| KEEP[Keep source + partial reason]
  KEEP --> OUTPUT
  OUTPUT --> REPORT[Public result report]
  PROCESS --- CACHE[Revisioned local cache]
