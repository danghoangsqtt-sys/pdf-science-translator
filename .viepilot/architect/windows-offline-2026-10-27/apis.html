API công khai theo profile

A01
MethodĐường dẫn đề xuấtPhản hồi / yêu cầu
GET/api/healthChỉ readiness trung tính; không danh tính engine.
GET/api/capabilitiesProfiles, nhãn, khả dụng, lý do công khai, phiên bản gói công khai.

Ví dụ DTO capabilities

A02
{
  "profiles": [
    {
      "id": "fast",
      "label": "Nhanh",
      "available": true
    },
    {
      "id": "balanced",
      "label": "Cân bằng",
      "available": true
    },
    {
      "id": "quality",
      "label": "Chất lượng cao",
      "available": false,
      "reason_code": "LOCAL_DATA_MISSING"
    }
  ],
  "default_profile": "balanced",
  "offline": true
}

offline: true chỉ được công bố khi runtime đang thi hành chính sách đã kiểm chứng. Schema đề xuất này chưa được cài vào sản phẩm.

Các dữ liệu phải dừng ở biên nội bộ

A03

Không trả model ID, tên nhà cung cấp, địa chỉ dịch, lệnh cài/tải, đường dẫn trọng số, raw traceback hoặc raw error response từ worker.

Thay route liệt kê engine cũ trong bản offline; đầu vào engine/model không được lặng lẽ chấp nhận. Token được sinh theo phiên; các route dữ liệu phải xác thực và chỉ bind loopback.

Lỗi công khai dùng allowlist: LOCAL_DATA_MISSING, LOCAL_DATA_INVALID, PROFILE_UNAVAILABLE, PROCESSING_FAILED. Chi tiết nội bộ không được nối thẳng vào thông báo.
