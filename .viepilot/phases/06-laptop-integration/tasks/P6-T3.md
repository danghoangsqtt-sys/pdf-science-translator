## File-Level Plan
- webui/backend/services/pack_service.py: Import manifest-listed files vào staging thuộc app-data, hash/quota/cancel, catalog ID ẩn danh và commit registry atomic.
- webui/backend/main.py: Endpoint token-auth nhận import/check/select theo schema rõ, 202 cho thao tác dài, không phản chiếu raw path/errors.
- webui/frontend/electron/main.ts: Directory picker local, kiểm tra sender, chọn registry cho lần mở sau; chỉ own backend/worker.
- webui/frontend/electron/preload.ts: Bridge tối thiểu cho chọn gói local, không expose filesystem/Electron API rộng.
- webui/frontend/src/electron.d.ts: Type bridge mới.
- tests/test_pack_service.py: Import interrupted/corrupt/traversal/reparse/disk-full/duplicate/busy và atomic rollback.
- tests/test_webui_backend.py: Import/select auth, canary privacy, schema validation và trạng thái thao tác dài.

## Implementation Notes
1. Không tải Internet hoặc hỗ trợ ZIP tùy ý trong đợt đầu; chọn thư mục pack local/USB và chỉ chép file đã khai báo sau kiểm tra schema/path.
2. Đích mới dưới app-data/packs/<id>, không viết vào USB nguồn, resources của bộ portable, model store hay thư mục bất kỳ do client chỉ định.
3. Chỉ publish catalog/selected pointer sau xác minh; duplicate digest reuse; đứt quãng giữ active pack trước đó. Không xóa model cũ để lấy chỗ.
4. Import có thể chuẩn bị riêng nhưng chỉ áp dụng gói ở lần khởi động lại do người dùng chọn khi không còn job; không đổi worker/policy giữa tác vụ.
5. Cleanup cancel chỉ được xóa staging vừa tạo thuộc namespace của thao tác, kiểm tra absolute boundary và reparse trước recursive delete.
6. Public chỉ ID ẩn danh/edition/profile/trạng thái; đường dẫn nguồn do picker cung cấp không phản chiếu vào response/log.
7. Từ chối platform/ABI khác và native worker/libs có hash khác runtime tin cậy trong app. Import gói dữ liệu không phải cơ chế cài executable/DLL mới; thêm ca hồi quy cho manifest tự khai hash của binary lạ.

## Best practices
Python 3.12 và venv repo; pathlib/type annotations, Windows subprocess có timeout/không shell.
Giữ nguồn/PDF/model/branding chưa commit; offline từ lần mở đầu, UI/API/log chỉ profile và lỗi trung tính.
Thay core PDF phải nhỏ và có hồi quy về marker/glyph/fit; không renumber/subset glyph IDs.
Cập nhật PHASE-STATE/TRACKER/HANDOFF khi thực thi; phân biệt verified kỹ thuật với PASS/persistence.
Không commit/push/tag/merge/ký số/phát hành hoặc xóa bộ portable người dùng đã xác nhận tốt.
