# BUG-006: Electron chọn venv Python 3.11 thay vì runtime 3.12 đã kiểm chứng

- **Type**: Bug

## Summary
Electron bản phát triển ưu tiên `.venv` cũ, trong khi toàn bộ gate cuối đã
chạy trên `.venv312`. Vì vậy mở ứng dụng chưa dùng đúng runtime đã kiểm chứng.

## Related
- Files: `webui/frontend/electron/main.ts`

## Resolution
Ưu tiên `.venv312` trong danh sách runtime phát triển. Luồng bản đóng gói vẫn
dùng Python runtime đi kèm như trước. Đã build và mở Electron thật, xác nhận
log chọn `.venv312/Scripts/python.exe`, backend lắng nghe 127.0.0.1:8089 và
giao diện hiển thị Backend/Ollama sẵn sàng.

## Acceptance Criteria
- [x] Backend thực tế dùng runtime 3.12 trong repo.
- [x] Bản build TypeScript/Vite đạt và cửa sổ thật kết nối API thành công.
